# Burgplatz · Durch die Zeit

Die interaktive Tour zeigt den Düsseldorfer Burgplatz in den Jahren 1869 und 1908 sowie in der Gegenwart. Diese Fassung enthält die statischen Dateien für GitHub Pages.

GitHub Pages aus dem Stammverzeichnis des Branches `main` veröffentlichen. In den Repository-Einstellungen unter **Pages** zuerst **Deploy from a branch** und dann **main** und **/(root)** auswählen.

Die Tour lässt sich lokal mit `python3 -m http.server 8080` öffnen. Sie benötigt einen Browser mit WebGL. Bildnachweise stehen in der Tour unter **Quellen & Rekonstruktion**, die Nachweise für die Figuren in `assets/npc/PROVENANCE.md`. Die mitgelieferten Lizenztexte gelten jeweils für die dort bezeichneten Bestandteile.
